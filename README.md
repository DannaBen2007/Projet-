# MailBox+

<h4>De l'intelligence même pour nos lettres</h4>

Ce projet permettra de concevoir une boîte aux lettres intelligente capable de détecter automatiquement l’arrivée d’un courrier. Il combine l’utilisation d’un capteur d’une carte électronique et d’une communication sans fil LoRa. Le système est simple mais représente une application concrète des objets connectés. Plusieurs améliorations pourront être envisagées comme l’ajout d’une application mobile, d’un compteur de lettres ou d’une alimentation autonome.
